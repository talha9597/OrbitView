# 🌌 OrbitView - Track Satellites in Real Time

## 🚀 Getting Started
Welcome to OrbitView! This app helps you visualize satellites in 3D and track their movements. You can see passes, predict future locations, and analyze potential conjunctions. Let’s get you set up.

## 📚 Features
- **3D Satellite Visualization:** View satellites from different angles in real-time.
- **Pass Prediction:** Get notified about when satellites will pass over your location.
- **Conjunction Analysis:** Analyze satellite proximity events to avoid potential collisions.
- **User-Friendly Interface:** Simple layout, easy to navigate even for beginners.

## 💻 System Requirements
- **Operating System:** Windows 10 or later, macOS Mojave or later, or a Linux distribution.
- **RAM:** Minimum 4 GB.
- **Storage:** At least 200 MB of free space.
- **Internet Connection:** Required for real-time data updates.
